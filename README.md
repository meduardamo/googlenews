# googlenews

Coleta de notícias via RSS e Google News RSS. Alimenta clipping geral/nacional e monitoramento subnacional (por UF).

## Arquivos
- `scraper.py` (geral/nacional)
- `scraper_subnacional.py` (subnacional por UF)
- `alinhamento.py` (rotinas auxiliares)
- `.github/workflows/main.yml` (GitHub Actions)
- `requirements.txt`
